# Code of conduct

Leani contributors must make participation respectful, constructive, and safe.
Harassment, threats, discrimination, sexualized conduct, publishing private
information, and sustained disruption are not accepted in project spaces.

Project maintainers may edit or remove contributions, comments, issues, and
other participation that violates this standard, and may temporarily or
permanently restrict participation. Enforcement decisions should consider
context, impact, recurrence, and a proportionate path to repair.

Report conduct concerns privately through the repository owner's contact form
or private GitHub security advisory. Do not include sensitive personal details
in a public issue. Maintainers will acknowledge reports privately, limit access
to the people needed to investigate, and disclose outcomes only as appropriate.

This policy applies in project repositories, community spaces, and when a
person is representing Leani publicly.
