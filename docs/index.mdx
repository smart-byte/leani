Leani is an Ethereum indexing node you run in your own infrastructure. It
backfills public history, follows the chain, and stores the results your
application needs. Start with one small example:

<CardGrid>
  <Card title="Run Leani" icon="rocket">
    [Install the alpha](/docs/getting-started/install/), then
    [follow an Ethereum block](/docs/getting-started/) or
    [index contract events](/docs/getting-started/bounded-mainnet/).
  </Card>
  <Card title="Connect an application" icon="database">
    [Query and subscribe with TypeScript](/docs/guides/query-then-follow/),
    then [persist changes to PostgreSQL](/docs/guides/postgres-consumer/).
  </Card>
  <Card title="Build with the Rust library" icon="puzzle">
    [Register your own processor, build a custom node, and query its output.](/docs/guides/custom-processor/)
  </Card>

Each tutorial includes a matching configuration, commands, and expected output.
The current alpha uses a source checkout; release packages become available
when published.

Leani does not maintain EVM state. Arbitrary `eth_call`, native account balances,
and transaction simulation need an execution provider. Read
[alpha limitations](/docs/operations/preview-limitations/) before connecting a
production application.

The expandable sidebar groups hold detailed concepts, API and configuration
reference, operations, and contributor material. Start with
[how Leani works](/docs/concepts/how-leani-works/) when you want to understand
what happens between a source block and your application output.
