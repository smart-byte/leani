The public package is `@smart-byte/leani-sdk`, for Node 20.3+ and Bun 1.2+. In a source
checkout, run `bun install --cwd packages/sdk` and `bun run --cwd packages/sdk build`.
The [query/follow guide](/docs/guides/query-then-follow/) includes an executable
client, a matching node config, and pagination/reset handling.

For a node started with `leani init blocks` and `leani serve`:

```ts
import { createLeaniClient } from "@smart-byte/leani-sdk";

const leani = createLeaniClient({ baseUrl: "http://127.0.0.1:18080" });
const stop = new AbortController();
for await (const change of leani.blocks.subscribe({ signal: stop.signal })) {
  if (change.operation === "apply" && change.data) {
    console.log(change.data.blockNumber);
  }
}
```

Pass an `AbortSignal` to cancel an idle subscription; breaking out of the loop
also cancels its response body. Transport disconnects reconnect from the last
yielded cursor. Protocol errors and expired history require application action.
An incomplete final event is discarded before reconnecting. Retryable HTTP
errors, including rate limiting, use the configured reconnect backoff, and so
do `error` events marked `retryable`; after five of them in a row without a new
change, the subscription throws the last one. A stream that sends nothing, not
even the node's 15-second keep-alive comments, for `idleTimeoutMs` (default
60,000) while the loop waits reconnects too. An event over 8 MiB fails the
subscription with a non-retryable `invalid_response` error.
This print-only example does not maintain state; stateful consumers must apply
undo mutations too.

A request that fails below HTTP rejects with `TransportError`, a `LeaniError`
with `status` 0, `code: "transport"`, `retryable: true`, and the runtime's error
as `cause`: a refused or reset connection, a response body that breaks off, a
passed deadline, or a silent stream. Aborting your own signal rejects with its
reason instead, and the SDK never retries it. The SDK does not follow
redirects: a 3xx answer rejects with the non-retryable `redirect_refused`, with
the target in `details.location`, so configure the final URL as `baseUrl`.
Every request path resolves under the base URL's path, one starting with `/`
included. A path segment that decodes to `.` or `..`, or holds a backslash, an
encoded slash or backslash (`%2F`, `%5C`), or an encoded percent sign (`%25`),
and a control character anywhere in the path, are refused before any request.
`request()` applies the same rule to a custom query extension's path, so a
path parameter whose value can hold `/` or `%` must move to the query string,
`request()`'s `params`.

Typed subscriptions accept `processor` to select a configured instance, for
example `leani.blobs.subscribe({ processor: "blobs-production" })`. The blobs
apply payload is `{ block, transactions }`. Narrow `operation` before reading
processor data: `finalized` carries `{ throughBlock }` instead. Discover canonical
query paths with `capabilities()` and pass `queryBasePaths` when aliases are
ambiguous.

`queryAndFollow()` returns the **first page** of an immutable snapshot and its
stream boundary. Follow every `nextCursor` with `queryEntities()`, release the
snapshot in `finally`, then subscribe from `boundaryCursor`. SSE resets throw
`ResetRequiredError`; HTTP expiry throws `LeaniError` with `code: "cursor_expired"`
or `"query_snapshot_expired"`. Rebuild the seed for either case.

`queryEntities()` also works when delivery is disabled; its `boundaryCursor`
and `recovery.follow` are then `null`. `queryAndFollow()` requires delivery and
returns a `FollowSnapshotPage` with a non-null boundary, or HTTP 409
`delivery_disabled`. The stream and change endpoints return the same error
when delivery is disabled.

Durable live/history sessions live in `@smart-byte/leani-sdk/backfill`. Construct them with
`createBackfillSubscriptionClient({ baseUrl, token, fetch, timeoutMs })`; both
entry points use the same `LeaniError` and `TransportError` classes and HTTP
error fields (`status`, `code`, `retryable`, `requestId`). The deadline applies
to JSON requests, lease renewals, and acknowledgements, and to a stream until
its hello arrives. An established stream that sends nothing, heartbeats
included, for three `heartbeatIntervalMs` while its iterator waits fails with a
`TransportError`; time spent handling a record does not count. A lease renewal
that fails with a retryable error is retried with backoff while the lease
holds; one that fails otherwise, or keeps failing until the lease would lapse,
ends the session at once, and the iterator throws its error. The lanes of
`subscribe()` reconnect after either, and after any other retryable error. A
stream record over 65 MiB fails the session with a non-retryable
`invalid_response` error. A backfill stream can request smaller batches with
`batching.maximumEncodedBytes`; `streamLive()` takes no batching option, so a
live stream's batches follow the node's
`api.delivery.live_batches.maximum_encoded_bytes`. Always close delivery
sessions in `finally`. Commit
idempotent destination writes before acknowledging a batch. Acknowledge a
batch's boundary, never a change's own cursor: the node refuses one inside a
live block or a history progress unit. A backfill session's `deliveryBatches()`
yields every boundary as `ackCursor` with the `events` it covers, including
batches without changes and the completion; `events()` flattens the changes
without boundaries. A consumer with a credential passes it as `credential`
on every call and stream. See
[durable delivery](/docs/concepts/durable-delivery/) for lease and reset semantics.
