## Build the release candidate

The tutorials use a source checkout, which also holds their example
configurations. To install the published preview instead, see
[published releases](#published-releases).
You need Git, Rust installed through rustup, and your platform's C/C++ build
tools. The repository's `rust-toolchain.toml` selects Rust 1.97.0 automatically.
The first build downloads dependencies and can take several minutes.

<CodeExample example="source-install" />

Expect `leani 0.1.0-rc.4`. If you already have the checkout, start at
`cargo build --locked -p leani` in its root directory.

`LEANI_SOURCE` points to the checkout; later tutorials use it to find example
configs. The `PATH` setting makes `leani` available in this terminal. In each
additional terminal, return to the checkout and run:

```bash
export LEANI_SOURCE="$PWD"
export PATH="$LEANI_SOURCE/target/debug:$PATH"
```

Continue with [your first Ethereum block](/docs/getting-started/).
For a check without network access, run the
[offline fixture](/docs/getting-started/offline-proof/).

## Prepare the TypeScript SDK

The examples use Bun 1.2 or later. From the checkout:

```bash
bun install --cwd packages/sdk --frozen-lockfile
bun run --cwd packages/sdk build
```

Repository examples resolve `@smart-byte/leani-sdk` to the local source. To use the built
package in your own application, run this from that application's directory:

```bash
bun add "$LEANI_SOURCE/packages/sdk"
```

Then follow the [query and subscription example](/docs/guides/query-then-follow/).
For Rust applications, see [build a custom node](/docs/guides/custom-processor/).

## Published releases

Install with `brew install smart-byte/tap/leani`, or choose a matching
archive from the [GitHub releases](https://github.com/smart-byte/leani/releases).
Verify the archive's published checksum and provenance before running it, as
[Verify a release](/docs/operations/verify-releases/) shows. Containers use
`ghcr.io/smart-byte/leani:v<version>`, such as `leani:v0.1.0-rc.4`; pin the
release's digest for deployment.

The Linux archives need glibc 2.39 or newer: Ubuntu 24.04, Debian 13, Fedora
40, RHEL 10 and its rebuilds, or a later release of these. On an older or
musl-based distribution, run the container image or build from source.
For this preview, select the `v0.1.0-rc.4` binary release and install the matching
SDK with `bun add @smart-byte/leani-sdk@0.1.0-rc.4`. An install without the exact version
resolves npm's `latest` tag, which may not match your node.
Keep binary, SDK, and configuration versions aligned with the release you selected.
